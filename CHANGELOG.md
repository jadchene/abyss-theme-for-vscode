# Changelog

## 1.1.8

- Renamed the extension and theme to Abyss Theme for VS Code.
- Updated repository metadata, documentation, and theme resource naming.

## 1.1.7

- Increased text-selection contrast in input fields with a neutral gray highlight that matches the pure-black theme.

## 1.1.6

- Use VS Code custom window controls so the minimize, maximize, and close area inherits the pure black title bar background in the latest VS Code.

## 1.1.5

- Set all `gitDecoration.*ResourceForeground` colors to pure white so Git tab decorations do not tint labels gray.

## 1.1.4

- Added supported unfocused and hover tab foreground colors to keep tab labels pure white after focus changes.

## 1.1.3

- Changed inactive tab labels to pure white instead of gray.
- Confirmed the issue was theme tab foreground settings, not user color overrides.

## 1.1.2

- Removed the unsupported `tab.unfocusedSelectedForeground` theme color key.
- Kept selected and active tab labels pure white with supported color keys.

## 1.1.1

- Fixed tab label foreground to stay pure white in newer VS Code tab states.

## 1.1.0

- Refined panel, menu, quick input, settings, and chat-related theme colors.
- Restored white editor default foreground while keeping Dark+ syntax highlighting.
- Adjusted hover, selection, and border tones for a more natural black UI.

## 1.0.0

- First stable release.
- Pure black interface and editor background.
- Dark+ syntax highlighting inherited via theme include.
