# Pure Black Theme

A minimal VS Code color theme with:

- pure black UI background
- pure black editor background
- default white foreground
- restrained grayscale syntax highlighting

## Local Packaging

Install `vsce` if needed:

```bash
npm install -g @vscode/vsce
```

Package the extension from this folder:

```bash
vsce package
```

Then install the generated `.vsix` file in VS Code.
